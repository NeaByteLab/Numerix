# util

Access every method through the namespace form `Numeric.util.method`.

## Methods

| Method              | Description                                   |
| ------------------- | --------------------------------------------- |
| [apply](apply.md)   | Runs an operation on each row of a matrix.    |
| [format](format.md) | Renders numbers using the requested notation. |
| [io](io.md)         | Parses delimited text or renders a matrix.    |
| [memory](memory.md) | Reports strides and ordering for an array.    |
