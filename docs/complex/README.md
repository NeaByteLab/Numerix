# complex

Access every method through the namespace form `Numeric.complex.method`.

## Methods

| Method            | Description                                         |
| ----------------- | --------------------------------------------------- |
| [angle](angle.md) | Reports the argument of each nested entry.          |
| [conj](conj.md)   | Negates the imaginary part of each entry.           |
| [imag](imag.md)   | Reads the imaginary component of each nested entry. |
| [real](real.md)   | Reads the real component of each nested entry.      |
