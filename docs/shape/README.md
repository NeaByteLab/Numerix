# shape

Access every method through the namespace form `Numeric.shape.method`.

## Methods

| Method                    | Description                                          |
| ------------------------- | ---------------------------------------------------- |
| [broadcast](broadcast.md) | Expands nested inputs to the requested dimensions.   |
| [expand](expand.md)       | Adds array levels around the given input.            |
| [flatten](flatten.md)     | Collects every leaf value into a single array.       |
| [flip](flip.md)           | Reverses rows, columns, or every axis.               |
| [insert](insert.md)       | Places values at the given index or appends them.    |
| [join](join.md)           | Concatenates or stacks the given arrays.             |
| [pad](pad.md)             | Adds entries around the array using the chosen mode. |
| [remove](remove.md)       | Drops the entries at the given positions.            |
| [repeat](repeat.md)       | Repeats the whole array or each entry separately.    |
| [reshape](reshape.md)     | Rearranges flattened values into the target shape.   |
| [resize](resize.md)       | Truncates or pads values to fit the target shape.    |
| [roll](roll.md)           | Moves entries from the end to the front.             |
| [rotate](rotate.md)       | Turns the matrix clockwise by the given count.       |
| [split](split.md)         | Divides the array into equal or sized sections.      |
| [squeeze](squeeze.md)     | Drops array levels that hold a single entry.         |
| [transpose](transpose.md) | Reorders the axes of a nested array.                 |
| [trim](trim.md)           | Trims leading or trailing zero values.               |
