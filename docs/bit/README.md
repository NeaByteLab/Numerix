# bit

Access every method through the namespace form `Numeric.bit.method`.

## Methods

| Method              | Description                                       |
| ------------------- | ------------------------------------------------- |
| [and](and.md)       | Combines operands with NumPy style broadcast.     |
| [count](count.md)   | Counts the active bits in each nested entry.      |
| [not](not.md)       | Flips every bit in the nested input.              |
| [or](or.md)         | Combines operands with NumPy style broadcast.     |
| [pack](pack.md)     | Groups bits into bytes using the requested order. |
| [shift](shift.md)   | Moves bits left or right by the given count.      |
| [unpack](unpack.md) | Expands each byte into its individual bits.       |
| [xor](xor.md)       | Combines operands with NumPy style broadcast.     |
