# dtype

Access every method through the namespace form `Numeric.dtype.method`.

## Methods

| Method              | Description                                      |
| ------------------- | ------------------------------------------------ |
| [cast](cast.md)     | Converts values or checks cast compatibility.    |
| [check](check.md)   | Matches the type against the category members.   |
| [endian](endian.md) | Reports endianness or reverses byte sequences.   |
| [info](info.md)     | Reports the range and storage details of a type. |
