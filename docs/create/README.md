# create

Access every method through the namespace form `Numeric.create.method`.

## Methods

| Method              | Description                                          |
| ------------------- | ---------------------------------------------------- |
| [array](array.md)   | Reshapes binary, textual, or numeric sources.        |
| [buffer](buffer.md) | Reads binary, textual, or generated values.          |
| [copy](copy.md)     | Clones nested values into a fresh container.         |
| [diag](diag.md)     | Reads or writes entries along the diagonal.          |
| [empty](empty.md)   | Builds a zero filled array of the given shape.       |
| [eye](eye.md)       | Builds a matrix with ones along the diagonal.        |
| [full](full.md)     | Builds an array of the given shape.                  |
| [mesh](mesh.md)     | Builds coordinate arrays for each grid axis.         |
| [one](one.md)       | Builds a one filled array of the given shape.        |
| [range](range.md)   | Generates evenly spaced values between two bounds.   |
| [space](space.md)   | Generates linear, logarithmic, or geometric spacing. |
| [tri](tri.md)       | Builds a matrix filled above or below the diagonal.  |
| [vander](vander.md) | Places powers of each sample into a matrix.          |
| [zero](zero.md)     | Builds a zero filled array of the given shape.       |
