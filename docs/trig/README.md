# trig

Access every method through the namespace form `Numeric.trig.method`.

## Methods

| Method              | Description                                                  |
| ------------------- | ------------------------------------------------------------ |
| [acos](acos.md)     | Applies the arccosine function across nested numeric inputs. |
| [acosh](acosh.md)   | Applies the inverse hyperbolic cosine across nested inputs.  |
| [asin](asin.md)     | Applies the arcsine function across nested numeric inputs.   |
| [asinh](asinh.md)   | Applies the inverse hyperbolic sine across nested inputs.    |
| [atan](atan.md)     | Uses atan2 when both operands are supplied.                  |
| [atanh](atanh.md)   | Applies the inverse hyperbolic tangent across nested inputs. |
| [cos](cos.md)       | Applies the cosine function across nested numeric inputs.    |
| [cosh](cosh.md)     | Applies the hyperbolic cosine across nested numeric inputs.  |
| [deg](deg.md)       | Scales each element by the radian to degree factor.          |
| [hypot](hypot.md)   | Combines operands element-wise with stable square roots.     |
| [rad](rad.md)       | Scales each element by the degree to radian factor.          |
| [sin](sin.md)       | Applies the sine function across nested numeric inputs.      |
| [sinh](sinh.md)     | Applies the hyperbolic sine across nested numeric inputs.    |
| [tan](tan.md)       | Applies the tangent function across nested numeric inputs.   |
| [tanh](tanh.md)     | Applies the hyperbolic tangent across nested numeric inputs. |
| [unwrap](unwrap.md) | Removes jumps larger than the discontinuity threshold.       |
