# poly

Access every method through the namespace form `Numeric.poly.method`.

## Methods

| Method                    | Description                                            |
| ------------------------- | ------------------------------------------------------ |
| [add](add.md)             | Aligns coefficients and sums them entry by entry.      |
| [companion](companion.md) | Creates the matrix whose eigenvalues are the roots.    |
| [convert](convert.md)     | Rewrites coefficients in the requested basis.          |
| [der](der.md)             | Applies differentiation repeatedly to reach the order. |
| [div](div.md)             | Performs polynomial long division.                     |
| [domain](domain.md)       | Reports bounds, maps values, or trims trailing zeros.  |
| [evaluate](evaluate.md)   | Computes polynomial values using Horner iteration.     |
| [fit](fit.md)             | Solves a least squares system for the coefficients.    |
| [gauss](gauss.md)         | Computes nodes and weights for a quadrature family.    |
| [grid](grid.md)           | Computes polynomial values at grid intersections.      |
| [int](int.md)             | Applies integration repeatedly to reach the order.     |
| [line](line.md)           | Creates coefficients for a straight line.              |
| [mul](mul.md)             | Convolves the coefficient arrays together.             |
| [pow](pow.md)             | Uses repeated squaring for the polynomial power.       |
| [root](root.md)           | Finds root values or the derived root polynomial.      |
| [sample](sample.md)       | Evaluates a polynomial or callback over sample points. |
| [sub](sub.md)             | Aligns coefficients and subtracts them entry by entry. |
| [vander](vander.md)       | Places powers of each sample into a matrix.            |
| [weight](weight.md)       | Evaluates the weight function at each point.           |
