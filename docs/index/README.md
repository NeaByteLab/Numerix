# index

Access every method through the namespace form `Numeric.index.method`.

## Methods

| Method                | Description                                                  |
| --------------------- | ------------------------------------------------------------ |
| [mask](mask.md)       | Generates coordinate pairs for a matrix pattern.             |
| [put](put.md)         | Assigns values into an array at the given positions.         |
| [ravel](ravel.md)     | Computes the row-major offset of a coordinate.               |
| [select](select.md)   | Chooses between alternatives using the given conditions.     |
| [slide](slide.md)     | Collects overlapping windows of the given length.            |
| [take](take.md)       | Reads entries from the given positions.                      |
| [unravel](unravel.md) | Computes the position of an offset along each axis.          |
| [where](where.md)     | Reports positions or picks values where the condition holds. |
