# stat

Access every method through the namespace form `Numeric.stat.method`.

## Methods

| Method                    | Description                                        |
| ------------------------- | -------------------------------------------------- |
| [average](average.md)     | Averages values using optional weights.            |
| [bincount](bincount.md)   | Tallies how often each integer appears.            |
| [corr](corr.md)           | Measures Pearson correlation or cross correlation. |
| [cov](cov.md)             | Measures how two signals vary together.            |
| [digitize](digitize.md)   | Reports which bin each value falls into.           |
| [histogram](histogram.md) | Counts values falling into each bin.               |
| [mean](mean.md)           | Averages values along the requested axis.          |
| [median](median.md)       | Selects the middle value of sorted entries.        |
| [quantile](quantile.md)   | Reports values at the requested probabilities.     |
| [std](std.md)             | Takes the square root of the variance.             |
| [variance](variance.md)   | Measures the spread around the mean.               |
