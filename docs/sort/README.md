# sort

Access every method through the namespace form `Numeric.sort.method`.

## Methods

| Method                          | Description                                    |
| ------------------------------- | ---------------------------------------------- |
| [argpartition](argpartition.md) | Reports positions split around the given rank. |
| [argsort](argsort.md)           | Reports positions that would sort the values.  |
| [order](order.md)               | Sorts numbers or complex values along an axis. |
| [partition](partition.md)       | Places the value at rank in sorted position.   |
| [search](search.md)             | Finds the insertion point of each target.      |
