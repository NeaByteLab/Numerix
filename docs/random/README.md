# random

Access every method through the namespace form `Numeric.random.method`.

## Methods

| Method                        | Description                                                     |
| ----------------------------- | --------------------------------------------------------------- |
| [beta](beta.md)               | Produces variates with the given shape parameters.              |
| [binomial](binomial.md)       | Produces counts of successes across fixed trials.               |
| [byte](byte.md)               | Fills a byte buffer with uniform random values.                 |
| [cauchy](cauchy.md)           | Produces heavy tailed variates around the origin.               |
| [chisquare](chisquare.md)     | Produces sums of squared standard normal variates.              |
| [choice](choice.md)           | Selects entries with or without replacement.                    |
| [dirichlet](dirichlet.md)     | Produces probability vectors from given concentration values.   |
| [exp](exp.md)                 | Produces variates with the given scale parameter.               |
| [fdist](fdist.md)             | Produces variance ratio variates from given degrees of freedom. |
| [gamma](gamma.md)             | Produces variates with the given shape and scale.               |
| [geometric](geometric.md)     | Produces counts of trials before the first success.             |
| [gumbel](gumbel.md)           | Produces extreme value variates with the given location.        |
| [integer](integer.md)         | Produces integers within an inclusive range.                    |
| [laplace](laplace.md)         | Produces symmetric variates around the given center.            |
| [logistic](logistic.md)       | Produces variates around the given center.                      |
| [logseries](logseries.md)     | Produces counts drawn from a logarithmic distribution.          |
| [multinomial](multinomial.md) | Produces counts across several outcome categories.              |
| [normal](normal.md)           | Produces variates around the given center.                      |
| [pareto](pareto.md)           | Produces heavy tailed variates above one.                       |
| [permute](permute.md)         | Shuffles an array or generates a random permutation.            |
| [poisson](poisson.md)         | Produces counts of events in an interval.                       |
| [power](power.md)             | Produces variates from a power law distribution.                |
| [rayleigh](rayleigh.md)       | Produces magnitudes of two dimensional normal vectors.          |
| [seed](seed.md)               | Builds a deterministic generator from an integer seed.          |
| [shuffle](shuffle.md)         | Rearranges entries using a Fisher-Yates pass.                   |
| [student](student.md)         | Produces heavy tailed variates with given freedom.              |
| [triangular](triangular.md)   | Produces variates between the bounds and the mode.              |
| [uniform](uniform.md)         | Produces variates spread evenly over the given range.           |
| [vonmises](vonmises.md)       | Produces circular variates around the given mean angle.         |
| [wald](wald.md)               | Produces positive variates with the given mean.                 |
| [weibull](weibull.md)         | Produces positive variates with the given shape.                |
| [zipf](zipf.md)               | Produces rank weighted variates from the given exponent.        |
