# string

Access every method through the namespace form `Numeric.string.method`.

## Methods

| Method                      | Description                                              |
| --------------------------- | -------------------------------------------------------- |
| [add](add.md)               | Joins matching entries of two string inputs.             |
| [align](align.md)           | Pads text using the requested alignment mode.            |
| [capitalize](capitalize.md) | Uppercases the first character and lowers the remainder. |
| [check](check.md)           | Matches each string against a named validation pattern.  |
| [count](count.md)           | Counts non-overlapping matches inside each string.       |
| [decode](decode.md)         | Converts byte buffers using UTF-8 encoding.              |
| [encode](encode.md)         | Converts strings into UTF-8 byte buffers.                |
| [equal](equal.md)           | Compares matching entries using the requested operator.  |
| [find](find.md)             | Reports the index of the first or last occurrence.       |
| [greater](greater.md)       | Reports whether the left string sorts after the right.   |
| [join](join.md)             | Inserts a separator between every character.             |
| [length](length.md)         | Counts characters in each string entry.                  |
| [less](less.md)             | Reports whether the left string sorts before the right.  |
| [lower](lower.md)           | Lowercases every string entry.                           |
| [mod](mod.md)               | Substitutes placeholders in the template string.         |
| [multiply](multiply.md)     | Concatenates each string with itself repeatedly.         |
| [pad](pad.md)               | Replaces tab stops with spaces up to the width.          |
| [partition](partition.md)   | Reports the text before and after the separator.         |
| [prefix](prefix.md)         | Checks the beginning of each string entry.               |
| [replace](replace.md)       | Swaps every match of the search string.                  |
| [slice](slice.md)           | Slices each string between the given bounds.             |
| [split](split.md)           | Splits each string on a separator or line break.         |
| [strip](strip.md)           | Trims characters from one or both ends.                  |
| [suffix](suffix.md)         | Checks the end of each string entry.                     |
| [swapcase](swapcase.md)     | Inverts uppercase and lowercase letters.                 |
| [upper](upper.md)           | Uppercases every string entry.                           |
