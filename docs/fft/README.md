# fft

Access every method through the namespace form `Numeric.fft.method`.

## Methods

| Method                | Description                                         |
| --------------------- | --------------------------------------------------- |
| [forward](forward.md) | Transforms a signal into its frequency spectrum.    |
| [freq](freq.md)       | Reports the frequency of each spectral bin.         |
| [hfft](hfft.md)       | Produces the half spectrum of a real signal.        |
| [ifft](ifft.md)       | Transforms a spectrum back into signal samples.     |
| [ihfft](ihfft.md)     | Rebuilds a real signal from its half spectrum.      |
| [irfft](irfft.md)     | Rebuilds a real signal from its frequency spectrum. |
| [rfft](rfft.md)       | Produces the positive bins of a real signal.        |
| [shift](shift.md)     | Moves the zero frequency bin to the array edge.     |
