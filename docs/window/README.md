# window

Access every method through the namespace form `Numeric.window.method`.

## Methods

| Method                  | Description                                        |
| ----------------------- | -------------------------------------------------- |
| [bartlett](bartlett.md) | Generates a triangular window of the given length. |
| [blackman](blackman.md) | Generates a cosine window of the given length.     |
| [hamming](hamming.md)   | Generates a symmetric cosine window.               |
| [hanning](hanning.md)   | Generates a symmetric raised cosine window.        |
| [kaiser](kaiser.md)     | Generates a window shaped by a Bessel function.    |
